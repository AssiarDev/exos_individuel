# 📚 Exercices Individuels – Ada Tech School  

Ce dépôt rassemble les exercices réalisés individuellement dans le cadre de ma formation à **Ada Tech School**, couvrant divers aspects du développement web et logiciel. Chaque série d'exercices permet d'approfondir des concepts clés et d'appliquer les meilleures pratiques en programmation.  

## 🚀 Contenu du dépôt  
Les exercices explorent différentes compétences techniques :  

- **Algorithmie et Logique** : Développement de la pensée algorithmique  
- **JavaScript** : Manipulation du DOM, gestion des événements et asynchronisme  
- **Node.js & Express** : Création d'API et gestion des bases de données  
- **SQL & PostgreSQL** : Requêtes et gestion avancée des données  

## 🛠️ Technologies utilisées  
- **Langages** : JavaScript, SQL  
- **Frameworks** : Node.js, Express, React  
- **Base de données** : PostgreSQL, SQLite  
- **Outils** : Git, VS Code, Jest
